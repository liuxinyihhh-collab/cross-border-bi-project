# 独立学习进度仓库建议

建议新建 `learning-progress` 仓库，和 BI 项目分别维护。它记录所有主题的学习掌握程度（业务、SQL、MySQL、Metabase、AI 等），而非仅记录项目完成情况。此文件是第二仓库的初始化模板，并不意味着它已经创建。

推荐目录：`logs/YYYY-MM-DD.md`、`reviews/YYYY-WW.md`、`skills/skill-matrix.md`。

## 每日记录
日期、学习时长、主题、目标、实际练习及证据链接、能独立完成什么、错误与改正、卡点、自评、需哥哥复核事项、下一步。

## 每周回顾
本周掌握证据、独立完成任务、仍需 AI 帮忙的部分、哥哥反馈、下一周练习重点。

学习内容由用户或 AI 根据实际练习记录；不要凭空给“已掌握”的结论。
